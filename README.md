# 判例脈絡：以 FEG 檢索支援 LLM 推理

這是一個面向作品集展示的互動式原型。系統將裁判書中的犯罪事實建置為法律事實事件圖（Fact Event Graph, FEG），以 FEG 向量檢索事實結構相近的歷史判決，再將相似案例與法規知識提供給大語言模型（LLM）。LLM 依法律三段論的推理脈絡產出建議，讓結果可回溯至檢索到的案例與法規依據，而非只依賴單一案件文字直接生成結論。

> 這是資訊檢索與分析展示，不構成法律意見、裁判預測或個案建議。

## 核心流程

```text
犯罪事實 → FEG 法律事件圖 → 圖向量檢索 → Top-k 相似案例＋法規知識 → 法律三段論 LLM 推理 → 可回溯的結果檢視
```

1. **FEG 建置**：將裁判書中的犯罪事實拆解為人物、涉案行為、犯罪原因、工具與後果等節點，以及節點間的因果、角色與序列關係。
2. **圖向量檢索**：以節點文字嵌入與圖結構共同表示案件，取得 Top-k 相似案例。
3. **法律三段論脈絡供給**：將法規知識庫與相似案例的事實、罪名、法條及結果作為大前提；以查詢案件的犯罪事實作為小前提；由 LLM 產出罪名、適用法條與推論結論。
4. **可追溯輸出**：使用者可查看 LLM 的建議罪名與法條，並回看每一件支撐推理的相似案例。

## 表徵與檢索設計

本專案中的「圖嵌入」是 **FEG 的 graph embedding，不是把圖譜當成圖片做 image embedding**：

1. 使用 Qwen3 Embedding 將每個 FEG 節點的事實文字轉為節點文字嵌入。
2. 將節點類型嵌入與文字嵌入結合，再以 Graph Attention Network（GAT）沿著 FEG 的有向連結聚合資訊，形成案件層級的圖向量。
3. 使用 Supervised Contrastive Learning（SupCon；另有 Triplet Loss 對照）拉近同罪名案件、拉遠不同罪名案件，建構用於相似案例檢索的法律向量空間。

相較於只將整段文字壓成單一向量，這種表示方式能保留「誰做了什麼、使用何種工具、造成何種結果」及事件的有向關係，因此能降低詞彙相似但角色、因果或行為結構不同所造成的檢索混淆。FEG 中的序列連結也保留事件先後的結構訊號。

目前模型以有向邊連結節點，但尚未將邊的關係類型或額外的時間位置編碼納入 GAT。因此，FEG 並非取代所有語意或時間推理；它是將事件角色、因果與順序納入案件表示。論文中的對照與消融實驗已驗證：相較於純文字向量基線，FEG 結合 GAT 與對比學習可提高相似案例檢索的精確程度；將檢索到的案例納入法律三段論脈絡，也能提升 LLM 推理的品質與可追溯性。

## 展示功能

- 五件人工挑選的查詢案例與各五件相近參考案例。
- 將犯罪事實建置為 FEG 法律事件圖：節點依角色、犯罪工具、原因、涉案行為與後果分類著色。
- 顯示 LLM 的 Top-k 檢索依據，並可切換、查看完整事實與圖譜。
- 呈現具案例脈絡的 LLM 推理結果與相近度。
- 事件圖支援滾輪局部縮放與拖曳平移，方便檢閱節點密集的案件。

## 專案結構

```text
app.py                       # 純 Python 標準函式庫的本機展示伺服器
assets/drawio/               # 30 張 FEG 法律事件圖 SVG 與來源檔
data/showcase_data.json      # 僅供展示的五組精選案例資料
tools/export_demo_data.py    # 從本機研究語料重建精選展示資料的工具
```

完整訓練／測試語料、批次推論輸出與模型權重並未納入此專案；它們體積大，且不屬於可公開展示所必需的內容。

## 研究範圍

本展示對應的研究設定以單一被告、單一主要罪名的刑事案件為主。複雜的多被告、多罪名或跨案件事件關係，仍是後續可擴充的方向；系統定位為研究與法律推理輔助工具，不取代專業法律判斷。

## 本機啟動

此版本不需要額外安裝套件。需使用 Python 3.10 以上：

```powershell
python app.py
```

開啟 [http://127.0.0.1:8780](http://127.0.0.1:8780)。

## 公開展示部署

此專案也包含不依賴後端的 `index.html`。展示資料與 FEG 事件圖 SVG 都以相對路徑載入，因此可直接部署到 GitHub Pages。

在 GitHub Repo 的 **Settings → Pages** 中，將來源設為 **Deploy from a branch**、分支選 **main**、資料夾選 **/(root)**，儲存後即可取得公開展示網址：

`https://hankchiu90.github.io/feg-legal-case-retrieval-demo/`

每次更新 `main` 分支後，GitHub Pages 會重新發布此靜態展示頁。
