# 判例脈絡：以 FEG 檢索支援 LLM 推理

這是一個面向作品集展示的互動式原型。系統先使用案件的事實事件圖（Fact Event Graph, FEG）檢索事實結構相近的歷史判決，再把這些案件的事實、罪名、法條與結果提供給大語言模型（LLM），讓推理具有可回溯的案例脈絡，而非只依賴單一案件文字直接生成結論。

> 這是資訊檢索與分析展示，不構成法律意見、裁判預測或個案建議。

## 核心流程

```text
查詢案件 → FEG 事實結構檢索 → Top-k 參考案例 → LLM 推理 → 可回溯的結果檢視
```

1. **FEG 檢索**：以人物、涉案行為、犯罪原因、工具與後果所組成的事件結構，比對查詢案件與歷史案例。
2. **案例脈絡供給**：將排名前五的參考判決連同其圖譜與事實，作為 LLM 的推理依據。
3. **可追溯輸出**：使用者可查看 LLM 的建議罪名與法條，並回看每一件支撐推理的參考案例。

## 展示功能

- 五件人工挑選的查詢案例與各五件相近參考案例。
- 以 Draw.io 製作並匯出的 FEG 事件圖：節點依角色、犯罪工具、原因、涉案行為與後果分類著色。
- 顯示 LLM 的 Top-k 檢索依據，並可切換、查看完整事實與圖譜。
- 呈現具案例脈絡的 LLM 推理結果與相近度。
- 事件圖支援滾輪局部縮放與拖曳平移，方便檢閱節點密集的案件。

## 專案結構

```text
app.py                       # 純 Python 標準函式庫的本機展示伺服器
assets/drawio/               # 30 張 SVG 事件圖及可編輯的 Draw.io 原始檔
data/showcase_data.json      # 僅供展示的五組精選案例資料
tools/export_demo_data.py    # 從本機研究語料重建精選展示資料的工具
```

完整訓練／測試語料、批次推論輸出與模型權重並未納入此專案；它們體積大，且不屬於可公開展示所必需的內容。

## 本機啟動

此版本不需要額外安裝套件。需使用 Python 3.10 以上：

```powershell
python app.py
```

開啟 [http://127.0.0.1:8780](http://127.0.0.1:8780)。

## 公開展示部署

此專案也包含不依賴後端的 `index.html`。展示資料與 Draw.io SVG 都以相對路徑載入，因此可直接部署到 GitHub Pages。

在 GitHub Repo 的 **Settings → Pages** 中，將來源設為 **Deploy from a branch**、分支選 **main**、資料夾選 **/(root)**，儲存後即可取得公開展示網址：

`https://hankchiu90.github.io/feg-legal-case-retrieval-demo/`

每次更新 `main` 分支後，GitHub Pages 會重新發布此靜態展示頁。

## 資料與公開注意事項

`data/showcase_data.json` 是為目前展示畫面整理的精簡資料，而非完整研究資料集。若要建立公開 GitHub 儲存庫，請在首次推送前完成個資與資料授權檢查；這個步驟會在上傳前另外確認。
